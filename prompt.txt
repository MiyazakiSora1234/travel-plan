# Shared
==================================================

shared/api/trips.tsにTrip APIを集約してください。

現在、

createTripApi(apiClient)

のような設計を採用しています。

この設計思想を維持してください。

例えば、

export function createTripApi(client: ApiClient) {
  return {
    create: (values: TripCreateFormValues) =>
      client.post<Trip>('/api/v1/trips', values),

    list: () =>
      client.get<Trip[]>('/api/v1/trips'),

    get: (id: string) =>
      client.get<Trip>(`/api/v1/trips/${id}`),
  }
}

のような形を基本としてください。

ただし実際の既存コードに合わせてください。

既存のcreate APIを壊さないでください。

==================================================
# Query Key
==================================================

TanStack Queryを使用している場合、
旅行計画のquery keyもsharedで管理してください。

例：

export const tripQueryKeys = {
  all: ['trips'] as const,

  list: () =>
    [...tripQueryKeys.all, 'list'] as const,

  detail: (id: string) =>
    [...tripQueryKeys.all, 'detail', id] as const,
}

既存のquery keyがある場合は、それを尊重してください。
